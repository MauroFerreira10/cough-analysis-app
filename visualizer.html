  • Processamento: 100% local (privacidade)

💻 Exemplos de Código

Python - Pré-processamento de Áudio

import librosa import numpy as np def load_and_process_audio(audio_path): # Carrega áudio em 16kHz mono audio, sr = librosa.load(audio_path, sr=16000, mono=True) # Normaliza audio = audio / np.max(np.abs(audio)) # Remove silêncio audio, _ = librosa.effects.trim(audio, top_db=20) return audio

Python - Extração de MFCC

def extract_mfcc(audio, sr=16000, n_mfcc=40): # Extrai coeficientes MFCC mfcc = librosa.feature.mfcc( y=audio, sr=sr, n_mfcc=n_mfcc, n_fft=2048, hop_length=512 ) # Estatísticas mfcc_mean = np.mean(mfcc, axis=1) mfcc_std = np.std(mfcc, axis=1) return np.concatenate([mfcc_mean, mfcc_std])

🚀 Próximos Passos

ℹ️ Recomendação: Use Google Colab (gratuito) para executar o projeto devido a incompatibilidades de biblioteca no seu macOS.

1️⃣ Configurar Ambiente (Escolha uma)

  • Google Colab (RECOMENDADO): https://colab.research.google.com/
  • Outro computador: Com Python 3.8+ e bibliotecas atualizadas
  • Cloud: AWS, GCP, Azure com GPU

2️⃣ Obter Dados

  • COUGHVID Dataset - 25K+ amostras
  • ICBHI Dataset - 920 sons respiratórios
  • Organize em: data/raw/normal/, data/raw/bronquite/, data/raw/pneumonia/

3️⃣ Executar Pipeline

# Pré-processa dados python src/preprocessing/prepare_data.py \ --input data/raw \ --output data/processed # Extrai características python src/preprocessing/extract_features.py \ --input data/processed \ --output data/features # Treina modelo python src/models/train_model.py \ --data data/features/features.pkl \ --output data/models # Converte para TFLite python src/models/convert_to_tflite.py \ --model data/models/best_model.h5 \ --output model.tflite

4️⃣ Testar App Móvel

# Configure Flutter cd mobile/cough_detector flutter pub get # Execute flutter run
